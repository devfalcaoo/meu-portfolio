# 📖 Sobre

Este projeto representa meu portfólio profissional como Desenvolvedora de Sistemas.

Foi desenvolvido para apresentar minha trajetória, experiências, competências técnicas e projetos, reunindo tudo em uma interface moderna, elegante e totalmente responsiva.

Além de funcionar como cartão de visitas profissional, este projeto demonstra conhecimentos em desenvolvimento Front-end, organização de código, boas práticas e experiência do usuário.
